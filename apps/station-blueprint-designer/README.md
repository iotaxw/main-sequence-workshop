# 空间站蓝图规划器（Station Blueprint Designer）

《主星序 Main Sequence》的离线 3D 空间站蓝图规划器：精密 CAD 线条艺术视角（暗/亮双主题）、高帧率键鼠交互、实时产线物流诊断、游戏原生 `.sav` ↔ JSON 全属性无损双向互转，以及本地文件夹 / 内置库 / 个人 GitHub 私有云库三合一蓝图管理。

- **在线打开（GitHub Pages）**：https://iotaxw.github.io/main-sequence-workshop/station-blueprint-designer/

## 核心能力（Build `26639889`）

- **全量目录与双主题 3D 线条艺术**：内置 Build `26639889` 全部 27 种空间站模块（含 `2×2 B` 二层 3 格宽回字形可建挑台、1×1/2×2 垂直电梯井、2/3 型竖立太阳能板、上下对称炮塔等实测比例线稿）、36 种室内建筑与物流件（含 `7×7` 超级计算机与生长舱）及 83 条中英文配方；支持暗/亮两套 CAD 主题。
- **极简布局与直觉交互**：
  - **视口与楼层**：精简顶栏 + 右上悬浮坐标 HUD + 右侧竖排楼层叠片条（一键跳层、`V` 切上层隐透）；`视角 ▾` 内支持**无 UI 预览 (`H`)**（可拖拽旋转/平移视角，点按画布或 `Esc` 退出）；滚轮滞回切换「空间站 ↔ 建筑视野」（或 `` ` `` / `Tab` / 双击模块），`E / Q` 或 `Shift+滚轮` 升降楼层，`中键 / WASD / 空格+左键` 平移，`右键拖拽` 旋转俯仰（`G` 开关四向吸附），`右键短按 / Esc` 取消工具或关闭弹窗。
  - **选择、拆除与搬移**：选择态悬停直读配方、物品种类与带速档位；顶栏一键切换中/英文界面（`中 / EN`）；左键点选/框选，`Shift` 加选、`Alt` 减选（点击与拖拽对称），`B` 切换跨层框选层域；`X` 进入拆除刷（红叉准星 + 实时红框悬停，支持点拆 / 连续扫拆 / `Shift+拖` 红框选拆，整笔单步 `Ctrl+Z` 撤销）；`Ctrl+X / C / V` 剪切搬移与复制盖章（与单模块建造一致，空间站蓝图粘贴拼接支持**接口对齐绿色锁定高亮**），`R / Shift+R` 旋转 90°、`F / Shift+F` 镜头相对水平/垂直镜像（蓝图、选区、手持预览全通用），`C / 中键短按` 吸管复制完整配置。
  - **拉带与地下带（Shapez 2 首尾点击流）**：底部 `1~9` 分组栏与 `Tab` 组内换型；选中传送带后**左键点起点即可自动 L 拉带**（无需长按），途中**中键短按放锚点**、`Backspace` 退回上一锚点、`F` 换角、`R` 轮换终点朝向（自动跳过反向带）、`T` 开关跨障地下带、`Alt` 反向，再左键点终点落位；`Shift+左键` 点起点进入首尾自由手绘（途中按 `T` 潜入/钻出地下带）；待命时按 `T` 切换同级地下带；`O` 选中整条连通带。
- **轻量图纸体检（`体检 / Check`）**：纯图论 `O(V + E)` 确定性检查 3D 模块重叠、越界/重叠建筑、无效配方、断连/对冲/混料/错料/电梯断层与异型混叠，并给出静态额定满载产能与电力台账；默认只报真实故障，进出口点位可通过面板开关按需显示；点击画布标记与右侧面板双向定位。深度多工况稳态流率与反压分析保留于离线验证核心（`simulation.ts` / `verifier.ts`）。
- **原生 `.sav` ↔ JSON 双向互转**：内嵌共享 Rust/WASM 编解码核心（源码见仓库 `packages/ms-blueprint-codec/`），全量 27 模块 / 36 建筑 / 83 配方 / 81 物品及全部 7 类实机配置属性（配方、端口开关、分流/平衡器优先级与过滤、容器过滤与创造属性、2/8 槽对接口滤网与命名、深空天文台配方、采矿坞目标、电梯/传送器标签、地下带配对长度）实现双跳不动点一致；支持拖入 `.sav` / `.json`、导出原版整站 `.sav` 与 Mod 局部预设 `.preset.sav`。
- **三合一蓝图库与悬浮缩略图大库 (`L`)**：
  - **内置起步模板**：默认包含干净的 `2x2A-标准起步模板.json`；左侧极简名称栏与 `L` 悬浮俯视缩略图大库均支持**单击抓取盖章、双击打开编辑**。
  - **本地文件夹（100% 离线）**：通过浏览器 File System Access API 直接读写本机目录。
  - **个人 GitHub 私有云库（可选）**：在蓝图库 (`L`) 顶部直接配置个人私有仓库与仅授权该仓库 `Contents` 读写的 Fine-grained PAT，跨设备直连读写；Token 仅存本机浏览器，断开即同时清除 Token 与画布缓存。

## 本地克隆与离线运行

前置环境：Node.js 20+（推荐 Node 24）。

```bash
git clone https://github.com/iotaxw/main-sequence-workshop.git
cd main-sequence-workshop/apps/station-blueprint-designer
npm ci
npm run dev      # 本地热更新开发
npm test         # 运行核心几何、诊断、WASM .sav 双跳与云库测试
npm run build    # TypeScript 类型检查 + 生产构建
npm run preview  # 离线预览生产包
```
